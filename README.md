# Pixel Dungeon 
<div align="center"><img width="500" alt="banners" src="https://github.com/user-attachments/assets/c806e117-4056-4d39-9819-e70dc88de7fc" /></div> 

Pixel Dungeon is a traditional roguelike game with pixel-art graphics and simple interface for Android.

<img style="width:80px;" alt="banners" src="https://github.com/watabou/pixel-dungeon/blob/master/res/drawable-xhdpi/ic_launcher.png" />

> Original Pixel Dungeon: [Github](https://github.com/watabou/pixel-dungeon), [Google Play](https://play.google.com/store/apps/details?id=com.watabou.pixeldungeon), [Web-site](http://pixeldungeon.watabou.ru/), [Itch.io](https://watabou.itch.io/pixel-dungeon), [Blog](https://pixeldungeon.tumblr.com/)

* Web port of [Pixel Dungeon](https://gnojus.github.io/pixel-dungeon-gdx/) (1.9.2a)
